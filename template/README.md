# Vite + TypeScript + Oxc

A minimal vanilla TypeScript app with Vite, Oxlint, and Oxfmt.

Requires Node.js 20.19+ on the 20.x line, or 22.12+, and pnpm.

```bash
pnpm install
pnpm dev
```

Edit `src/main.ts` and `src/style.css` to get started.

| Command          | Purpose                                 |
| ---------------- | --------------------------------------- |
| `pnpm dev`       | Start the development server            |
| `pnpm typecheck` | Check TypeScript                        |
| `pnpm build`     | Check TypeScript and build into `dist/` |
| `pnpm preview`   | Preview the production build locally    |
| `pnpm lint`      | Run Oxlint                              |
| `pnpm lint:fix`  | Apply available lint fixes              |
| `pnpm fmt`       | Format files with Oxfmt                 |
| `pnpm fmt:check` | Check formatting                        |

Lint configuration lives in `.oxlintrc.json`; formatter configuration lives in
`.oxfmtrc.json`. Commit the lockfile generated by your first install.
